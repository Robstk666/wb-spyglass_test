# 🤖 WB Competitor Analyzer — Telegram Bot

Бот для анализа конкурентов на Wildberries прямо в Telegram.

---

## ⚡ Запуск за 5 шагов

### Шаг 1 — Установи Python-зависимости
```bash
pip install -r requirements.txt
```

### Шаг 2 — Создай бота у @BotFather
1. Открой Telegram, найди @BotFather
2. Отправь `/newbot`
3. Придумай имя и username (например `wb_analyzer_bot`)
4. Скопируй токен вида `1234567890:AAxxx...`

### Шаг 3 — Получи WB-токен
Это главный шаг. WB требует специальный cookie (`xwb-token`) для API.

**Вручную (рекомендуется):**
1. Открой Chrome, перейди на wildberries.ru
2. Нажми **F12** → вкладка **Application**
3. В левом меню: **Storage → Cookies → https://www.wildberries.ru**
4. Найди строку `xwb-token`, скопируй значение из колонки **Value**

Токен живёт ~2 недели. Когда перестанет работать — повтори шаг.

### Шаг 4 — Создай файл .env
```bash
cp .env.example .env
```
Открой `.env` и заполни:
```
TG_TOKEN=1234567890:AAxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
WB_TOKEN=eyJ0eXAiOiJKV1Qi...  ← вставь xwb-token сюда
```

### Шаг 5 — Запусти бота
```bash
python bot.py
```

Открой Telegram, найди своего бота, отправь `/start` 🎉

## 💬 Команды бота

| Команда | Что делает |
|---------|-----------|
| `/start` | Приветствие и список команд |
| `/analyze 123456789` | Топ-5 конкурентов |
| `/analyze 123456789 10` | Топ-10 конкурентов |
| `/rank 123456789 джинсы` | Позиция товара в поиске |

| `123456789` | Просто отправь артикул — сразу анализ |

**Артикул** — число из URL страницы товара:
`wildberries.ru/catalog/`**`123456789`**`/detail.aspx`

## 🧠 Как работает анализ

### Алгоритм
```
Артикул
 ↓
1. Ищем товар в поиске WB → получаем название + цену
 ↓
2. Первые 3 слова названия → поисковый запрос
   "Джинсы женские прямые" → ищем по "Джинсы женские прямые"
 ↓
3. Берём первые 100 результатов поиска
 ↓
4. Фильтр по цене: оставляем только ±30% от цены вашего товара
 ↓
5. Считаем demand_score для каждого конкурента
 ↓
6. Сортируем по demand_score ↓ → топ-5
```

### Метрика demand_score (0–100)

```
demand_score = отзывы×40% + рейтинг×30% + продажи×30%
```

Товар с высоким score — сильный конкурент: у него много покупателей, хороший рейтинг и стабильный спрос.

### Почему нужен xwb-token

С 2024 WB использует JS-антибот: при первом открытии сайта браузер решает challenge и получает cookie `xwb-token`. Без него API возвращает HTTP 498. Поэтому нужно получить токен из реального браузера.

## 🔧 Частые проблемы

### Бот не отвечает
- Проверь, что `python bot.py` запущен и нет ошибок в консоли
- Убедись, что TG_TOKEN в `.env` правильный

### Ошибка 498 / "токен не настроен"
- Токен WB устарел (живёт ~2 недели)
- Повтори шаг 3 — получи новый xwb-token из браузера
- Обнови WB_TOKEN в файле `.env`
- Перезапусти бота

### "Конкуренты не найдены"
- Товар в очень узкой нише — мало аналогов
- Попробуй другой артикул для проверки

### Бот зависает на анализе
- WB API может медленно отвечать
- Анализ занимает 5–15 секунд — это нормально
